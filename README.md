# Grocery list using React + Vite

Jason Gentile

This is a grocery list application that uses React + Vite

## Functionality:

- Takes user input and stores the string, with a unique ID generated by Date module
- Renders these strings in bullet point form as a list
- If User presses enter, uses Add button's function to also add to list that way
- Edit in place
- Quantity handling
- delete items from list (filter)
- basic warm styling, green, orange, and cream
- Running total of all items across all quantities using reduce
- error message for submitting an empty name field

## Components:

- App.jsx: root component. Owns the grocery list state and defines all handler functions (addItem, editItem, deleteItem). Passes data and handlers down to child components as props. Uses `map` to render the list, `filter` to delete items, and `reduce` to calculate the total item count.

- GroceryItem.jsx: Represents a single grocery list entry. Receives item data and handler functions as props from App. Manages its own local edit state — toggling between display mode (showing name, quantity, Edit and Delete buttons) and edit mode (showing input fields with Save and Cancel buttons).
