# Grocery list using React + Vite

This is a grocery list application that uses React + Vite

## Functionality:

- Takes user input and stores the string, with a unique ID generated by Date module
- Renders these strings in bullet point form as a list
- If User presses enter, uses Add button's function to also add to list that way
- WIP: Edit in place, delete items from list (filter), styling, reduce (counter?)

## Components:

- GroceryItem.jsx: single function, takes id and name props and returns a list of names
